# Minha configuração NixOS + KDE Plasma 🐧

Este repositório reúne minha configuração pessoal do NixOS, utilizando o KDE Plasma como ambiente gráfico.

## Objetivo

Manter um sistema funcional, organizado e simples de administrar, instalando apenas o necessário para meu uso diário.

## Filosofia

- Simplicidade e praticidade.
- Evitar programas e serviços desnecessários.
- Priorizar estabilidade e facilidade de manutenção.
- Fazer mudanças com cuidado, sem mexer no que está funcionando.

## Aviso

Esta configuração foi criada para meu próprio computador. Ela serve como referência e ponto de partida para outras pessoas, mas pode exigir adaptações de acordo com o hardware, os programas e as necessidades de cada usuário.

Antes de aplicar qualquer configuração, revise o conteúdo e consulte a documentação oficial do NixOS.

## Sistema

- Distribuição: NixOS
- Ambiente gráfico: KDE Plasma
- Sessão gráfica: Wayland

A configuração será atualizada conforme mudanças relevantes no meu sistema.
